### ZMK keyboard layout

A Corne layout based on Miryoku (Colemak-DH, home-row mods), with a gaming layer, a mouse
layer and French accents.

### US or Canadian French

The left half has two builds with the same layout. Flash the one that matches your Windows
keyboard layout:

- `corne_left-nice_nano_v2-zmk.uf2`: US layout. Accents are typed with Alt codes (Num Lock on).
- `corne_left-nice_nano_v2-canadian_french.uf2`: Canadian French layout. Accents use the
  layout's own dead keys.

Symbol keys in the keymap use the `K_*` names from `config/locale.h` (generated by
`tools/gen_locale.py`), so both builds stay in sync.

### Building locally

With Docker Desktop running: `.\build-local.ps1`, or `.\build-local.ps1 left` for the left
half only. Firmware lands in `..\firmware\`. GitHub Actions builds the same files on every push.

### Windows tools

- `tools/layer_overlay.pyw`: always-on-top window showing the active layer (Ctrl+Alt+K to show
  or hide). Layer keys send unused F13–F24 keys as signals, which the tool hides from other apps.
  Restart it after keymap edits.
- `tools/battery_tray.pyw`: tray icon with both halves' battery levels.

Install with `pip install bleak pystray pillow` and run with `pythonw`.
